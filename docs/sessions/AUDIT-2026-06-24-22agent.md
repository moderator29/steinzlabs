## 1. Executive Summary — Top 12 Truths

1. **The entire cron fleet is frozen for ~6 weeks.** Every `cron_execution_log` job has `max(completed_at) = 2026-05-13`; likely `CRONS_PAUSED=true` (`lib/cron/_shared.ts:10`) or a detached deployment. This is the single upstream cause of most "stale data" findings.
2. **Whale Live Feed returns ZERO rows for every user, every filter.** All 53,929 `whale_activity` rows have `value_usd = NULL` while the feed filters `.gte('value_usd', minUsd)` (`app/api/whale-tracker/feed/route.ts:90`). Data also stops 2026-05-13.
3. **Swaps never execute and never persist — but the UI says "confirmed".** `InlineBuySellForm` prints "Bought/Sold" on any 200 without signing/broadcasting (`components/market/InlineBuySellForm.tsx:224-228`); `/dashboard/swap/page.tsx:1029-1032` sets `confirmed` on broadcast before any receipt poll.
4. **Every swap-logging write targets columns that don't exist.** `swap_logs`/`fee_revenue` writers insert `input_token/output_token/wallet_address/fee_bps` etc.; live schema is `token_in/token_out/amount_in/amount_out/fee_usd` and `usd_value/fee_amount`. Result: `swap_logs=0`, `fee_revenue=0`, `transactions=0` rows. The 0.4% platform fee is never recorded.
5. **`/api/swap/execute` does not exist** — every inline SwapCard + `useSwapExecution` POSTs to it and 404s (`components/vtx/SwapCard.tsx:198`, `lib/hooks/useSwapExecution.ts:121`).
6. **The entire Dune intelligence tier is a Potemkin village.** 17 `dune_*` tables (plus `funding_rate_snapshots`, `goplus_security_cache`) were never applied to the live DB; 6 UI strips + 5 crons read tables that error→null→permanent empty state.
7. **Fabricated whale leaderboard data violates the no-mock-data rule.** `pnl_30d_usd == whale_score × $1M`; Paradigm and a16z both exactly `$97,000,000 / $1,564,000,000`. The PnL-backfill cron that would replace them is hard-broken (writes non-existent `pnl_5d_usd`).
8. **DM realtime never delivers and read receipts are dead.** Browser client never calls `realtime.setAuth()`, so RLS (`auth.uid()` NULL for anon) drops every `postgres_changes` event; the PATCH `read` endpoint is never invoked. All DM tables = 0 rows.
9. **DM private-key wrap secret is `SHA-256(rotating access-token JWT)`** (`lib/social/encryption.ts:60-72`), rotated ~hourly by `autoRefreshToken`, with no re-wrap and no regeneration fallback → permanent lockout from history on first refresh.
10. **Reputation cron dead 35 days; top-traders board hard-broken.** `user_reputation` has 1 row (last computed 2026-05-20); `scorer.ts:138` queries `swap_logs.pnl_usd` which does not exist (table has `fee_usd`), swallowed by `.catch(()=>null)`.
11. **"Add Custom Token" is broken end-to-end.** Stores a bare contract while the hydrator needs `<chain>:<contract>` (`app/dashboard/wallet-page/page.tsx:548-550,723`), hardcodes balance/value to `'0'`, has no DB persistence, and rejects all Solana addresses.
12. **Multiple flagship controls are dead theatre:** `/dashboard/market` Filters button has no `onClick` (FiltersModal imported nowhere); Whale Directory Timeframe pills never read by the API; Smart Money settings toggles are static divs; several settings/security CTAs and the digest email link 404.

## 2. Cross-Cutting Themes

**A. Frozen crons (root cause of "staleness").** Whole fleet stopped 2026-05-13. Cascades into: empty whale feed, stale reputation, empty convergence, no PnL backfill, no pricing. Fixing the scheduler is prerequisite to ~30% of findings. Add cron-failure alerting + a `last_run` health check; several crons (`whale-backfill-pnl`, `copy-trade-monitor`) also log `success` even when every write fails.

**B. Schema drift between code and live DB (financial-grade).** Repeated pattern of writers/readers using column names that don't exist:
- `swap_logs`: code uses `input_token/output_token/input_amount/output_amount/wallet_address/swap_type/amount_usd/from_token/pnl_usd`; live has `token_in/token_out/amount_in/amount_out/price_impact/fee_usd/dex/status/tx_hash`.
- `fee_revenue`: code uses `fee_usd/fee_bps/input_token/input_value_usd/wallet_address`; live has `fee_amount/fee_token/usd_value/tx_hash/user_id/chain`.
- `sniper_executions`: code orders by `created_at`/reads `amount_usd`; live has `executed_at/buy_amount_usd`.
- `notification_settings`: API writes 14 `*_enabled`/`quiet_start` columns that don't exist; live has `whale_alerts/smart_money/price_alerts/quiet_hours_*_minute`.
- `whales`: cron writes `pnl_5d_usd` (doesn't exist).
All swallow errors and report success. **Add a CI insert-roundtrip contract test so drift fails the build.**

**C. Fabricated / synthetic data presented as real.** Whale leaderboard formulaic seed values; Top Whales Today synthesizes "24h volume" from portfolio×turnover; market buy/sell ratio defaults to fabricated 50/50; transactions status defaults to "confirmed"; swap "confirmed" without receipt. All violate CLAUDE.md "Mock Data — Forbidden."

**D. Dead filters / toggles / orphaned components.** Whale Directory Timeframe pills, market Filters button + FiltersModal + TimeframeSelector + WatchlistGrid/PricesTable/OrderBook cluster, Smart Money settings toggles, MEV-protect toggle, slippage picker (no-op against 0x), wallet "By Change" sort (= By Value), chain-filter pill side-effects. Label pills use a taxonomy (`smart_money/cex/mm/bot/insider/bridge`) with zero overlap with live `whales.entity_type` (`dev/exchange/fund/influencer/institutional/trader/unknown/vc`).

**E. Broken funnels (UI lies about success).** Swap "confirmed"; follow modal "you'll get alerts" (no alert pipeline consumes `user_whale_follows`); settings "Settings saved" (silent insert failure); add-token security scan never runs; "Live"/"Encrypted"/"LIVE" badges over empty/stale/undelivered data.

**F. Empty-in-production tables behind finished UIs.** `transactions`, `swap_logs`, `fee_revenue`, `dm_*`, `wallet_clusters`, `whale_watchlist`, `holder_snapshots`, `user_copy_rules`, orders tables, all `*_preferences` tables (0 rows). Many features ship as permanent empty states.
