# Naka Labs — Consolidated Platform Audit (2026-06-24)

Synthesis of 19 surface auditors against the live Supabase project `phvewrldcdxupsnakddx`. Benchmarked against best-in-class 2030 platforms (Nansen, Arkham, GMGN, Photon, Phantom, DexScreener, Dune). This is read-only analysis; all evidence is `file:line` plus live-DB queries the auditors ran.

---

## Executive Summary

The platform ships polished, best-in-class-looking UIs over **multiple completely hollow or broken data pipelines**. The unifying failure mode is the same across nearly every surface: a writer never runs (or targets a non-existent table/column), the UI reads an empty table, and an always-on "Live" / "real on-chain data" badge masks the void. Several surfaces additionally **fabricate synthetic data and present it as real**, which is the single highest reputational risk and an explicit violation of the platform's no-mock-data mandate.

**Root-cause clusters (fix these and ~60% of findings clear):**

1. **The cron fleet is frozen.** Cron execution logging stopped 2026-05-13 (42 days). `whale_activity` ingestion, price backfill, reputation scoring, and Dune refresh have produced zero new rows since. The `CRONS_PAUSED` kill switch is on. 45% of crons (23/51) never log at all, so failures are invisible.
2. **The Dune materialized-view architecture (11 tables) was never deployed.** Migrations exist; the live DB has zero `dune_*` tables. This cascades into Intelligence Tier, Context Feed, Swap pre-trade intelligence, Whale enrichment, and 17 VTX AI tools — all return empty while showing "loading" or fallback states forever. Several crons silently upsert into these missing tables.
3. **The trade-recording pipeline is broken end-to-end.** `swap_logs`, `fee_revenue`, and `transactions` are all 0 rows in production. `recordSwapLog()` silently returns when `user_id` is null (non-Naka wallets), so real volume vanishes. Portfolio PnL, tax-loss, wash-trade, revenue analytics, and copy-trade PnL all read these empty tables.
4. **Schema drift between code and live DB.** Code writes enum values and columns the live constraints/schema reject (`user_copy_trades.status` = `alert`/`blocked_*`; `swap_logs.swap_type`; `sniper_executions.pnl_usd`; admin `feature_flags` vs `platform_settings`; settings written to `user_preferences` with non-existent columns). These inserts fail silently.
5. **Fabricated data presented as real** appears on at least five surfaces (whale volume/PnL, portfolio history, Proof "on-chain assessment" prose, README whale counts).
6. **Admin auth is fractured and insecure.** A modern RBAC system exists but is dead code (0 rows in `admin_roles`); 9+ routes and middleware still use legacy `profiles.role='admin'`; the admin bearer token sits in plaintext `sessionStorage` and is treated as un-audited `super_admin`.

## P0 — Money / Trust / Data-Integrity (fix first)

### Fabricated / synthetic data presented as real (top reputational risk)
- **Whale "Top Whales Today" synthesizes volume** from `portfolio × trade_rate` when `whale_activity` is empty — a $100M portfolio shows $100M synthetic volume as real. `app/api/whale-tracker/top-today/route.ts:58-81`. **Return empty panel; do not synthesize.**
- **Whale PnL fabricated** (`pnl == whale_score × $1M`, a16z shown as $97M, synthetic 24h volume) per `HANDOFF-2026-06-24-autonomous.md:118`. Surfaces in whale profiles.
- **Portfolio history fabricated**: `usePortfolio.ts:137-166` `generateEstimatedSnapshots()` invents 90-day daily snapshots (0.85 baseline + linear gradient), regenerating differently on cache expiry. **Show "Historical data unavailable" until real snapshots exist.**
- **Proof "On-chain Assessment" fabricated prose** with a footer falsely claiming "Rule-based assessment from live on-chain metrics — not AI-generated." `app/dashboard/proof/page.tsx:359-387` (e.g. "Deep liquidity pools ensure minimal slippage for trades up to $50K"; "Contract verification…all pass our security checks" with no data fetched). **Remove or replace with raw GoPlus/Dune values.**
- **README/docs whale count fabricated 50×**: "15K+ verified whale wallets" vs live `COUNT(*)=291`. `README.md:27`, `docs/feature-documentation.md:99`. Plus blanket "no mock feeds, no synthetic numbers" claim (`README.md:11`) is currently false.

### Broken data pipelines (UI reads tables nothing writes; writers hit missing tables/columns)
- **`whale_activity.value_usd` 100% NULL across 53,929 rows** → whale feed filters `gte('value_usd', minUsd)` and returns empty. `app/api/whale-tracker/feed/route.ts:90`. Latest row 2026-05-13 (41 days stale).
- **`swap_logs` = 0 rows, `fee_revenue` = 0 rows, `transactions` = 0 rows in production.** No `INSERT INTO transactions` exists anywhere. `recordSwapLog()` silently returns when `user_id` is null (MetaMask/Phantom users without a Naka wallet), so their swaps vanish. `lib/trading/swapLogging.ts:45-54`; `app/api/portfolio/performance/route.ts:97-104`. **Consequence:** Portfolio PnL, tax-loss, wash-trade, revenue analytics all read empty → permanently zero.
- **Dune 11-table architecture never deployed to live DB** (`dune_holder_concentration`, `dune_smart_money_score`, `dune_bridge_flows`, `dune_wash_trade_score`, `dune_token_age_buyers`, `dune_stablecoin_pulse`, `dune_cex_flow`, `dune_first_buyer_performance`, `dune_insider_wallets`, `dune_cluster_aggregates`, `dune_mev_loss_aggregate`). Migrations `2026_05_21_dune_integration.sql` + `2026_05_22_dune_audit_gap_closures.sql` exist but were never applied. `dune-refresh`, `first-buyer-performance:175`, `insider-wallet-detector:99` upsert into them and fail silently. Cascades into Intelligence Tier, Context Feed Dune cards (all 8 types empty), Swap intelligence, whale enrichment, 17 VTX tools. (Human-gated — see migration section.)
- **`goplus_security_cache` table missing** → Swap UI honeypot/tax detection blind (`honeypot_flag='unknown'`). `lib/dune/useSurfaces.ts:446`.
- **Cron execution logging frozen since 2026-05-13** — `cron_execution_log` zero entries for 42 days → total blindness into cron health. `app/api/cron/_shared.ts:109`.
- **Gasless swap endpoints 404** — `/api/gasless/quote|submit|status` called but routes don't exist; with gasless on, the swap flow crashes / 60s poll times out telling users to "Check wallet" though nothing was submitted. `app/dashboard/swap/page.tsx:922-944`.
- **Admin broadcast recipient counts always "—"**: page expects `totalUsers/proUsers/freeUsers/inactiveUsers` but `/api/admin/stats` returns a different schema. `app/admin/broadcast/page.tsx:30-38` vs `app/api/admin/stats/route.ts:60-78`.
- **Admin broadcast audience filter non-functional**: form sends `audience`, API expects `targetTier` → defaults to `all` every time; `inactive` unsupported. `broadcast/page.tsx:55` vs `broadcast/route.ts:8-11`.

### Schema-drift writes that fail silently (constraints/columns reject them)
- **`user_copy_trades.status` constraint excludes `alert` and `blocked_*`** but `lib/copy/matcher.ts:217` writes `alert` (alerts-only mode) and `execute/route.ts:129,136,140,144,161,189,326` write `blocked_rule`/`blocked_security`. Every such insert violates the CHECK constraint. (Human-gated migration to restore enum values.)
- **`copy_mode` enum mismatch**: `user_whale_follows.copy_mode` ∈ {alerts, oneclick} vs `user_copy_rules.mode` ∈ {alerts_only, oneclick, auto_copy} — incomplete migration, both columns coexist with incompatible enums.
- **`swap_logs.swap_type` column does not exist** but swap page sends `swapType='gasless'|'standard'`; silently dropped. `swap/page.tsx:1068`.
- **Admin feature flags write to wrong table**: `POST /api/admin/settings` upserts `platform_settings` (singleton, no `key` column) instead of `feature_flags`; fails but still returns `ok:true`. `app/api/admin/settings/route.ts:31`.
- **Settings page writes notification/trading prefs to `user_preferences`** with non-existent columns (`whale_alerts`, `default_slippage`, …); the table only has `(user_id, preferences jsonb, …)`. Silent failure, cross-device sync never happens. `app/settings/page.tsx:166-176`.

### Dead controls shown as security/protection
- **MEV protection toggle has zero effect** — `mevProtect` is destructured but never read; no Flashbots/Jito routing. Users get a false sense of security. `swap/page.tsx:867` → `app/api/market/trade/execute/route.ts:51`.
- **Static `ADMIN_BEARER_TOKEN` = un-audited super_admin** — bypasses the permission matrix and skips audit logging entirely. If leaked, untracked super_admin actions (delete/ban/impersonate). `lib/auth/adminAuth.ts:77-80,149`. (Token rotation/removal is human-gated.)
