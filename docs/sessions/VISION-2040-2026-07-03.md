**Beast features:**

### Ask the Graph — Natural-Language Onchain Query 🤖AI
- **What:** User types 'show me wallets that funded this token's top 10 holders and also touched Tornado Cash' or 'which cluster accumulated $WIF before the Binance listing'. Claude translates the sentence into a structured graph-traversal plan (seed addresses, hop count, edge-type filters, risk overlays), the server executes it over wallet_edges + Alchemy/Helius transfers, and the answer renders as a highlighted subgraph plus a plain-English summary with cited tx hashes.
- **Pipeline:** Claude (tool-use JSON: text->traversal spec) -> executor queries Supabase wallet_edges + on-demand Alchemy getAssetTransfers / Helius; optional Sim-by-Dune SQL for holder sets; GoPlus/RugCheck for token risk; renders via existing d3 force graph. Upstash rate-limits Claude spend per user.
- **Moat:** Nansen/Arkham/Bullpen require you to manually click through filters and hops. Nobody lets you interrogate the fund-flow graph in English and get a rendered, evidence-cited subgraph back. This is the single most 'wtf is this beast' surface.
- **Novelty:** Text-to-graph traversal with cited on-chain evidence — replaces the entire manual filter UI with a sentence.

### Fund-Flow Time Machine (temporal causal replay) 🤖AI
- **What:** A scrubber replays how capital actually moved through a cluster over time — animated particles travel along d3 edges in chronological order, wallets light up as they receive/send, and a Claude-narrated caption describes each phase ('Hour 0: single funder seeds 8 wallets; Hour 3: all 8 buy $TOKEN within 90s; Day 2: coordinated exit'). Detects the causal funding-then-coordination signature visually.
- **Pipeline:** wallet_edges.first_seen_at/last_seen_at + whale_activity timestamps + Alchemy/Helius per-tx blockTime; frames bucketed server-side; Claude Haiku generates per-phase narration cached in Supabase. Renders on the existing d3 graph with requestAnimationFrame particle tweening, reduced-motion aware.
- **Moat:** Nansen shows a static Sankey; Arkham shows a static graph. Neither replays the temporal causal sequence that PROVES coordination. Seeing 8 wallets fund-then-fire in sync is undeniable evidence, and it is genuinely beautiful.
- **Novelty:** Time-scrubbed causal fund propagation with AI phase narration — turns a static blob into a proof-of-coordination movie.

### Sybil Genome — behavioral embedding clustering 🤖AI
- **What:** Computes a behavioral fingerprint vector per wallet (tx-timing entropy, gas-bid distribution, token-overlap set, funding lineage depth, hold-duration profile) and clusters wallets by cosine similarity in pgvector — catching sybils that deliberately AVOID direct fund links (the hard case graph-only detection misses). Claude explains why two seemingly-unrelated wallets are the same operator.
- **Pipeline:** whale_activity + Sim-by-Dune SQL for feature extraction -> feature vector -> Supabase pgvector (new wallet_fingerprints table) -> cosine kNN -> merge into wallet_edges as behavioral_fingerprint edges. Claude Haiku writes the human explanation.
- **Moat:** Every existing tool clusters by fund flow or shared funder. Sophisticated farmers launder through mixers to break those links. Behavioral-embedding matching is how you catch them anyway — a defensible detection edge worth acquiring.
- **Novelty:** Catches disconnected sybils via behavioral similarity, not fund links — the detection nobody else has.

### Autonomous Cluster Watchdog Agent 🤖AI
- **What:** For any watchlisted cluster, a Claude agent runs on a cron, diffs the cluster's new on-chain activity against its baseline, and fires a natural-language alert when something matters: 'Insider Ring 0x9f.. just reactivated after 40 days dormant — 8 wallets accumulated $340k of $PEPE in 4 minutes, 6h before an unannounced CEX deposit.' Pushed via VAPID + Telegram.
- **Pipeline:** cron -> lib/agents/cluster-agent.ts (already scaffolded with tool-use) -> Alchemy/Helius fresh transfers + DexScreener price -> Claude decides significance -> VAPID push + Telegram + Supabase cluster_alerts feed.
- **Moat:** Competitors give you dashboards you must watch. This watches for you and speaks. cluster-agent.ts already exists — the moat is autonomy + narration, not raw data.
- **Novelty:** An autonomous analyst that narrates coordinated moves in real time instead of a passive dashboard.

### Cross-Chain Entity Unification (Bridge Genome) 
- **What:** Merges an actor's EVM and Solana addresses into a single Entity by matching bridge out/in events on (amount, time-window, known bridge contract) plus behavioral fingerprint confirmation, then presents one unified cross-chain fund-flow graph and combined P&L.

### Cluster P&L + Alpha Attribution

- **Moat:** Bullpen/Nansen let you follow whales blind. Turning follow into an evidence-based, backtested decision (with drawdown, not just PnL) is the trust bridge that converts a viewer into a copier — and it's all replay of data already indexed.
- **Novelty:** No mainstream whale tracker offers a per-wallet copy-trade backtest with drawdown before you commit capital.

- **Moat:** Everyone streams 'whale bought X'; nobody quantifies 'and historically this wallet's buys of this size move price +A% within B hours' or auto-explains intent. Directly actionable for entries.
- **Novelty:** Predictive per-wallet price-impact bands + an AI intent classifier on each move are unseen in competitor whale feeds.

- **Moat:** Copy-trading platforms show only forward, cherry-pickable stats; a rigorous, reproducible historical backtester is the trust layer that makes copy-trading safe and defensible.
- **Novelty:** No onchain product lets you replay to a block AND backtest a copy strategy with slippage — this is quant-desk tooling brought to retail.
